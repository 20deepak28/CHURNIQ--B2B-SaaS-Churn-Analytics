# ChurnIQ – B2B SaaS Customer Churn Analytics

## Overview
ChurnIQ is a B2B SaaS Customer Churn Analytics project developed using Power BI, Python, and SQL. It focuses on analysing customer churn, subscription performance, revenue trends, and customer retention through data-driven insights.

## Objectives
- Analyse customer churn patterns and customer behaviour.
- Monitor Monthly Recurring Revenue (MRR).
- Understand customer retention and subscription performance.
- Identify trends that can support customer retention strategies.

## Technology Stack
- Power BI – Interactive dashboards and data visualization
- Python – Data processing and analysis
- Pandas & NumPy – Data manipulation
- SQL – Data querying and analysis

## Key Metrics
- Customer Churn Rate
- Monthly Recurring Revenue (MRR)
- Customer Retention
- Subscription Performance

## Project Highlights
- Customer churn analysis
- Revenue and retention analysis
- Interactive Power BI visualizations
- Business-focused analytical insights
